# App screenshots

These JPEGs show the charcoal and blue interface in a running FluentTube app, using an isolated demo database and synthetic content. They contain no personal library entries, user recordings, provider credentials or third-party video frames.

- `library.jpg`: a sample library with in-progress, new and completed videos.
- `dictation.jpg`: a completed sample sentence in the dictation workspace.
- `speaking.jpg`: the unlocked speaking workspace before recording.

The sample video frame ("Small steps. Real progress.") was generated locally for these captures. Its silent audio track is a placeholder; this screenshot fixture does not demonstrate speech recognition accuracy. No real user progress was changed.

Temporary demo services and fixtures live in the ignored `logs/` directory and are not required to run the app.
